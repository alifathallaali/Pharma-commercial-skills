# Contributing

## Skill requirements
Every new skill should include:
- SKILL.md
- clear inputs and outputs
- decision framework
- assumptions handling
- evidence requirements
- QA checklist
- at least one synthetic example

## Quality rules
1. Never fabricate evidence.
2. Distinguish facts from assumptions.
3. Make calculations reproducible.
4. Avoid universal recommendations when local market context is missing.
5. Flag missing data.
6. Keep pharma/compliance context explicit.
